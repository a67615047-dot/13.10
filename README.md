#   Sekmīga noteikšana

Šī ir vinkārša Python programma, kas palīdzs skolēnam noskaidrot viņa sekmību mācību gada noslēgumā, balstoties uz ievadīto gada atzīmi.

##  Programmas nosacījumi un loģika 
Programma pieprasa lietotajam ievadīt savu gada vērtējumu kā veselu skaitli (no 1 līdz 10) un veic šādu pāebaudi:
* ** Ja vērtējums ir 4 vai augstāks :** tiek izvadīts paziņojums '" Esi veiksmīģi pabeidzis mācību gadu! "'
* ** Citadi (ja vertējums ir mazāk par 4):** tiek izvadīts pazinojums '" Vel ir iespēju diena vai vasaras darbs!"'

#  Projekta struktūra 
Projekts sastāv no šādiem failiem
- programmas_gads < - - GALVENAIS FAILS (Palaidiet šo, lai darbinatu programmu)
- README.md       < - - Šis apraksts un galvenais fails

## Lietošanas funkcijas
1.parliecinieties, ka jūsu datorā ir uzsdādīts Python
2.Atveriet un palaidiet failu programmas_gads
3.Kad terminālī parādās aicinājums, ievadiet savu atzīmi (piemēram '7') un nospiediet **[Enter]**.
4.Ekrana uzreiz parādīsies atbilstošais paziņojums par mācību gada noslēgumu.
